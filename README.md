# LONA

Two static pages. No build step, no server, no dependencies.

- **index.html** — overview of the LONA research platform: what works, the two
  candidate strategies and their caveats, the findings, and the roadmap.
- **terminal.html** — a live read-only terminal. Reads Hyperliquid's public API
  directly from the browser and computes both strategy books on every load.

Neither page holds a key, stores anything, or can place an order. The only thing
that identifies a user is a wallet address typed into the page, which stays in
that browser's URL bar and is a public blockchain address in any case.

Research only. Not financial advice.
